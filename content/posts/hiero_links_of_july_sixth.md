## Hiero Links For The Week Of July 6th

This week featured a lot of new and exciting updates within the Hiero Organization. 
Below are links to some of things that happened this past week. **Check it out!**

---
**[Angelina C](https://github.com/aceppaluni)** updated the [linked issue](https://github.com/hiero-ledger/hiero-sdk-python/pull/2379) enforcer workflow in the Python SDK to close PR’s after two hours if an issue is not linked. 

**[Simon Vienot](https://github.com/svienot)** updated [vue dependencies](https://github.com/hiero-ledger/hiero-mirror-node-explorer/pull/2617) and corrected defineModel constructs inside the Hiero Mirror Node Explorer. 

**[Ivo Yankov](https://github.com/Ivo-Yankov)** fixed a [one-shot deployment hang](https://github.com/hiero-ledger/solo/pull/4952) by ensuring the mirror pinger task completes when the local configuration is missing, and added troubleshooting guidance for the SOLO-3035 error to recommend a full environment cleanup in Hiero Solo.
 
**[Michael Heinrichs](https://github.com/netopyr)** merged the [consensus-state-management module into consensus-state](https://github.com/hiero-ledger/hiero-consensus-node/pull/26238), consolidating the state management code and removing the standalone module in Hiero Consensus Node.
