## Hiero Links For The Week Of July 13th

This week featured a lot of new and exciting updates within the Hiero Organization. 
Below are links to some of things that happened this past week. **Check it out!**

---
**[Angelina C](https://github.com/aceppaluni)** added a [PR dashboard](https://github.com/hiero-ledger/hiero-enterprise-java/pull/223) to Hiero Enterprise Java to track PR changes in real time. 

**[Daniel Ntege](https://github.com/danielmarv)** updated the [bot-pr-missing-linked-issue workflow](https://github.com/hiero-ledger/hiero-sdk-python/pull/2435) in the Python SDK to improve security and simplify the repository checkout process.

**[Kelly Greco](https://github.com/poulok)** corrected a consensus [optimization bug](https://github.com/hiero-ledger/hiero-consensus-node/pull/26319) in Hiero Consensus Node to return the use of nGen.

**[Jessica G](https://github.com/jwagantall)** added a blog post to the Hiero Website outlining the success of the [Hiero Community day](https://github.com/hiero-ledger/hiero-website/pull/531) event in Berlin.
