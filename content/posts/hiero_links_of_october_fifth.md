## Hiero Links For The Week Of October 5th

This week featured a lot of new and exciting updates within the Hiero Organization. 
Below are links to some of the things that happened this past week. **Check it out!**

---
**[Giuseppe B](https://github.com/Neurone)** updated the [runner environment](https://github.com/hiero-ledger/hiero-solo-action/pull/160) for validation jobs in Hiero Solo Action.

**[Dian D](https://github.com/ddeskov-limechain)** fixed [topic query retries](https://github.com/hiero-ledger/hiero-sdk-js/pull/4477) to preserve the original subscribe time when retrying before the first message, preventing messages from being skipped when the initial request fails in the JavaScript SDK.

**[Mustafa U](https://github.com/mustafauzunn)** refactored [File Append](https://github.com/hiero-ledger/hiero-sdk-java/pull/2981) in the Hiero Java SDK.

**[Noah T](https://github.com/Ndacyayisenga-droid)** dropped the [SNAPSHOT](https://github.com/hiero-ledger/hiero-enterprise-java/pull/376) qualifier from all modules for the 0.21.0 release of Enterprise Java.
