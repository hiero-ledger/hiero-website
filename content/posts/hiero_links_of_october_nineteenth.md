## Hiero Links For The Week Of October 19th

This week featured a lot of new and exciting updates within the Hiero Organization. 
Below are links to some of the things that happened this past week. **Check it out!**

---
**[Ahmethan K](https://github.com/AhmethanKalenderoglu)** updated the [token creation transaction end-to-end tests](https://github.com/hiero-ledger/hiero-sdk-python/pull/2739) to use the shared environment fixture in the Python SDK.

**[Aditya A](https://github.com/Adityarya11)** added the [getFileInfo TCK Endpoint](https://github.com/hiero-ledger/hiero-sdk-go/pull/1868) to the Go SDK.

**[Michael H](https://github.com/netopyr)** improved performance by [replacing for-each loops and a stream](https://github.com/hiero-ledger/hiero-consensus-node/pull/27789) with index-based loops on the hot path in Hiero Consensus Node. 

**[Jan M](https://github.com/jan-milenkov)** improved [Windows Docker workflow reliability](https://github.com/hiero-ledger/solo/pull/6260) by adding retries with backoff to the Docker exec probe, enhancing failure diagnostics, and pinning the Docker daemon version to 29.9.2 in Hiero Solo.
